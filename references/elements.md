# 元素设计与占位

## 形状来自原码

先取原矩阵并标记功能区域，再统计数据区可用的暗格组合。不要要求每张二维码都使用下面全部形状；无法自然组合的位置用单点或其他已确认的小物填充，不移动、补增或删除格点。

| 占位例子 | 轻奢女装例子 | 开业例子 | 主要适配点 |
| --- | --- | --- | --- |
| 1×1 单点 | 包布纽扣、宝石点 | 小金币 | 中心有足够深色面积；高光和孔洞不侵占主要采样区域 |
| 2×1 横块 | 棉布蝴蝶结 | 剪彩结、元宝 | 翼部/两端不能细到消失；中心结仍覆盖对应暗格 |
| 多格横块 | 展开腰带、布带 | 金条、剪彩带 | 保留宽实主体；不随意旋转成斜线 |
| 1×2 竖块 | 服装吊牌 | 红包 | 孔洞、绳结、封口不破坏主要深色区域 |
| 1×3 竖块 | 线轴、竖向配件 | 礼花筒 | 筒口与喷彩需辨认；彩带不能散入浅格或静区 |
| 2×2 满块 | 针织上衣、叠放面料 | 叠放金条 | 四个暗格都得到覆盖；领口、倒角不能挖掉关键区域 |
| 2×2 中三格组成 L | 直角短袜、回弯布带 | 弯折剪彩带 | 按缺格方向旋转，缺格保持浅/透明；可用竖块＋单点组合 |
| 主定位专用 | 包布纽扣、织物框 | 打开的礼盒 | 外深、内浅、中心深的空间关系；完整码试装验证 |
| 辅助校正专用 | 小纽扣、缝线标 | 小礼盒 | 单独设计其比例和细节；不能直接套用主定位的装饰量 |

尺寸与组合只是占位例子。对复杂连通区域，选择更小的物件拼合比强行拉伸某个大图标更可靠。旋转、镜像、裁切后的物件也要看实物辨识度，尤其是衣物、文字和带方向的配件。

## 生成提示的必要内容

按本次主题写提示，不继承历史主题的固定色卡：

- 物件清单及各自目标比例；各物件互相分离，边缘不被截断。
- 一致的视角、光源、材质尺度；颜色可有差异，但缩小时仍保持足够的亮暗区别。
- 关键深色区域在哪里、哪些空缺必须透明。对 L 形明确三个实心区域和一个空缺区域。
- 高光、金边、褶皱和阴影的允许范围；不要求全面哑光来换扫码。
- 真正透明背景，避免脱离物件的长投影。无标签、伪文字、品牌标志、二维码或布局网格，除非用户明确要求物件上的这些内容。

大元素设计板适合讨论，不直接作为最终素材。需要时展示“放大细节＋实际入码大小”：如果缩小后看不出是烟花、礼花筒或服饰，先改轮廓、主体比例和细节密度。

## 光泽与明度

照片中的光泽是固定的像素分布。问题通常是亮区域取代了关键深色结构，而不是“金色不能使用”或“必须换颜色”。优先保留金条顶面、倒角和窄边高光，调整正面主要采样区域；先试自然物理明暗，不画可见的控制横线和纯色补块。

分别记录：色相是否符合主题、材质是否能辨认、明度是否影响识别。全局压暗会把亮金变得像铜，也会压掉布面质感；全局压平光泽则可能通过某些解码器，却不满足视觉要求。

可用 [适配脚本](scripts.md) 的保亮部增益或局部阴影区域。若亮反射恰好占据关键采样位置，先试切片改变亮面的位置或宽度，让原有自然阴影承担深色结构；不需要把整件金属换色。所有坐标从本次素材测量，不能照搬某个元宝的切片。

时序、格式与版本暗格同样需要主题元素。选定的小金币、纽扣等可以单格适配；保持位置信息、浅格和分隔区，重新检验实际成品。不得把未经用户选择的纯色方块混进成品充当扫码补丁。

## 定位造型

主定位与辅助校正不是任意装饰。造型可以圆润或带物件特征，但还要维持检测所需的空间亮暗结构。礼盒可利用深色盒壁、浅内衬与深色礼物形成层次；盒盖、锁扣和大蝴蝶结的位置需要适配。

先在完整原码上分别测试选定的红/蓝/绿素材及实际混色组合，再测试最终海报。不要从“绿色单色定位通过”推断三色组合一定通过。自然烟花的细线、亮中心、疏松轮廓可能不适合承担定位，可作为静区以外的装饰；这是具体候选的结果，不能推断所有异形定位都不成立。

## SVG 导出

每件元素提供独立、自包含文件，带准确的 `viewBox` 和透明背景。对齐方式、目标占位、裁切范围与版本写进简短的素材记录，避免只交一张整板 SVG。

- **保留照片质感：**将实际用到的高清透明 PNG 内嵌进 SVG；SVG 负责尺寸、几何、裁切和组合。注明“内嵌位图，非纯矢量”，保留 PNG 原件。这不是自动获得无限放大质量。
- **纯矢量：**使用路径、填色、渐变和必要的 SVG 效果重建；渐变也能表达光泽，但照片级微纹理通常要简化。输出不能藏有栅格图片；渲染后重新检查效果。

统一质感与色彩不意味着每件物件只有同一颜色。纯矢量也不等于必须哑光；不要把格式取舍和亮度取舍混成一个问题。
